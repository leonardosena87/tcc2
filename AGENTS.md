# Orientações deste projeto

- Este projeto é versionado em `leonardosena87/tcc2`, na conta GitHub usada pelo projeto Sena Imóveis.
- Mantenha código, testes, instruções e materiais de trabalho pertinentes neste repositório. Ao concluir alterações autorizadas, registre o trabalho no Git e envie ao repositório conforme a solicitação do usuário.
- Preserve os documentos originais e alterações locais não relacionadas. Não substitua materiais acadêmicos sem que a tarefa peça isso.
- Nunca versione chaves da API, tokens, certificados privados, arquivos `.env`, credenciais DPAPI, dependências instaladas ou arquivos temporários. A credencial local do suplemento fica fora deste workspace, em `%LOCALAPPDATA%/TccAssistente/credentials`.
- Antes de cada commit, confira o conteúdo preparado e os arquivos ignorados. Este repositório é público.
- Execute os testes pertinentes em `tcc-assistente` antes de enviar mudanças de código. Distinga testes simulados, chamadas reais à IA e verificações dentro do Word/Revit/AutoCAD.
